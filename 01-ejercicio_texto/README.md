# Ejercicio 01: Estilos de Texto y Selectores

El objetivo principal de este ejercicio es practicar la aplicación de estilos básicos de CSS3, el uso de unidades relativas (`em`) y la jerarquía de selectores (IDs y clases).

## 📋 Requisitos del Ejercicio

Para este ejercicio, se aplicaron las siguientes reglas de estilo:

1.  **Fuente Base:** Configuración del `body` con color negro, tipografía Arial, tamaño `0.9em` e interlineado `1.4`.
2.  **Encabezados de Artículos:** Los `h2` dentro de la clase `.articulo` utilizan el color `#CC6600`, tamaño `1.6em` e interlineado `1.2`.
3.  **Menú de Navegación:** Enlaces en color blanco con tamaño `1.3em` y fondo del contenedor en color azul.
4.  **Barra Lateral:**
    * Texto general de `#lateral` a `0.9em`.
    * Fechas de noticias en color gris claro (`#999`).
5.  **Sección Noticias:** Los títulos `h3` (enlaces) configurados en color `#003366`.
6.  **Publicidad:** Texto en gris oscuro (`#555`) y enlaces en color naranja cobrizo (`#CC6600`).
7.  **Cuerpo de Artículos:** Los enlaces dentro de la clase `.articulo` mantienen el color `#CC6600`.

## 📂 Archivos del ejercicio

* `texto_1.html`: Estructura de la página.
* `texto_1.css`: Hoja de estilos con las reglas aplicadas.
